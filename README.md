# Conservation_Genomics

These scripts are intended for conservation genomics studies involving population diversity, inbreeding, putative genetic load, donor prioritization, and forward simulations of genetic rescue.

You are welcome to use, cite, and discuss this project.

## Timeline
- **2022** — Project initiated.
- **July 2024** — Version 0.1 released.
- **June 2025** — Version 0.2 released.
- **July 2026** — Version 0.3 released.

## Citation
The manuscript describing this project is currently under review.

## Reproducibility
The repository includes scripts for:
- population diversity and inbreeding analyses
- putative deleterious variant and LOF analyses
- donor prioritization
- forward simulations

The original scripts are provided to reproduce the analyses reported in this study.

The parameterized versions are provided for reuse and adaptation.
